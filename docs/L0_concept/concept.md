# L0 Concept: Nuts Launcher

## プロダクトの目的

Ubuntu 24.04 LTS / GNOME Wayland 環境において、アプリやシステム操作などへ素早くアクセスできる、軽量でシンプルな最小ランチャーを提供する。

## 解決する問題

日常的な操作に素早くアクセスでき、作業の流れを妨げないランチャーを提供する。

## 対象ユーザー

- Ubuntu 24.04 LTS / GNOME Wayland 環境を使うユーザー
- キーボードを中心に、日常的な操作へ素早くアクセスしたいユーザー

## 設計の考え方

- **軽量・高速**: 日常的に繰り返す操作へ素早くアクセスできることを重視する。
- **シンプル**: 操作と構成を分かりやすく保ち、不必要な複雑さを持ち込まない。
- **最小ランチャー**: ランチャーとしての役割に必要な範囲を見極め、機能追加によって使いやすさやシンプルさを損なわない。
- **責務の分離**: FEP/IME 切替は別の仕組みに委ね、ランチャーの責務と分離する。
- **環境との調和**: GNOME Wayland 環境に適した仕組みを使い、既存の環境との共存を重視する。

個別機能の採否や具体的な動作は、この考え方に照らして別途定める。
